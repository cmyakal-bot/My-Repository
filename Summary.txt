Summary

1.Built a Python-based DNS monitoring tool using Scapy to capture DNS   queries for a configurable 2-minute period.

2.Extracted each DNS query's timestamp and domain name and stored them in dns_queries.log.

3.Captured real DNS traffic from the Linux system while filtering DNS packets on port 53.

4.Built a separate analysis script using Python's Counter to calculate the most frequently queried domains.

5.Produced a Top 5 DNS queries report, demonstrating packet capture, logging, parsing, and basic network-traffic analysis.
